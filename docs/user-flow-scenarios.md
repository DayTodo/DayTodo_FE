# DayTodo 사용자 흐름 시나리오

이 문서는 `feature/59-home-api`와 `feature/58-course-api` 기준으로 구현된 홈, 코스 생성, 코스 참여, 코스 목록, 장소 추천 및 코스 구성 흐름을 사용자 관점에서 정리한다.

## 1. 홈 화면

### 1.1 홈 진입

1. 사용자가 로그인 또는 자동 로그인을 완료한다.
2. 앱은 홈 화면으로 진입한다.
3. 홈 화면은 코스 정보와 오늘의 매거진 정보를 불러온다.
4. 사용자는 상단 배너, 진행 중인 코스, 생성한 방, 오늘의 Pick 매거진, 확장 FAB를 확인한다.

### 1.2 상단 배너 확인

1. 사용자는 상단 배너에서 본인의 닉네임과 관심 지역을 확인한다.
2. 오늘 진행 중인 코스가 있으면 "오늘 {관계}의 일정이 있어요!" 메시지를 본다.
3. 오늘 코스는 없지만 예정 코스가 있으면 "곧 다가오는 일정이 있어요!" 메시지를 본다.
4. 예정된 일정이 없으면 "오늘은 아무 일정이 없어요." 메시지를 본다.
5. 저장 아이콘을 누르면 저장 화면으로 이동한다.
6. 캘린더 아이콘을 누르면 캘린더 화면으로 이동한다.

### 1.3 진행 중인 코스 확인

1. 사용자는 "진행 중인 코스" 섹션을 확인한다.
2. 오늘 진행 중인 코스가 있으면 코스명, 날짜, 관계 유형, 참여 멤버를 확인한다.
3. 오늘 진행 중인 코스가 없으면 빈 상태 안내를 확인한다.

### 1.4 생성한 방 확인

1. 사용자는 "생성한 방 보러가기" 섹션을 확인한다.
2. 예정 코스가 있으면 코스 카드 목록을 가로로 스크롤한다.
3. 각 카드에서 코스명, 날짜, 참여 인원 수, D-Day, 관계 유형 색상을 확인한다.
4. 섹션을 누르면 예정 코스 목록 화면으로 이동한다.
5. 생성한 방이 없으면 빈 상태 안내를 확인한다.

### 1.5 오늘의 Pick 매거진 확인

1. 사용자는 "오늘의 Pick! 매거진" 섹션을 확인한다.
2. 관심 지역 기준으로 추천된 매거진 목록을 본다.
3. 매거진 카드에서 장소명, 지역명, 소개 문구, 썸네일을 확인한다.
4. 매거진 카드를 누르면 매거진 상세 화면으로 이동한다.

### 1.6 홈 FAB 사용

1. 사용자는 홈 화면의 확장 FAB를 누른다.
2. "새 코스방 만들기"를 선택하면 코스방 생성 흐름으로 이동한다.
3. "초대된 그룹 들어가기"를 선택하면 초대 코드 입력 흐름으로 이동한다.

## 2. 코스방 생성

### 2.1 코스방 이름 입력

1. 사용자는 홈 FAB에서 "새 코스방 만들기"를 선택한다.
2. 코스방 만들기 화면의 1단계로 진입한다.
3. 사용자는 코스방 이름을 입력한다.
4. 이름을 입력하면 다음 단계 버튼이 활성화된다.
5. 다음 단계 버튼을 눌러 지역 선택 단계로 이동한다.

### 2.2 코스 지역 선택

1. 사용자는 지역 선택 필드를 누른다.
2. 지역 선택 다이얼로그에서 상위 지역과 하위 지역을 선택한다.
3. 선택한 지역이 입력 필드에 표시된다.
4. 다음 단계 버튼을 눌러 날짜 선택 단계로 이동한다.

### 2.3 코스 날짜 선택

1. 사용자는 날짜 선택 필드를 누른다.
2. 날짜 선택 다이얼로그에서 코스 날짜를 선택한다.
3. 오늘 이전 날짜는 선택할 수 없다.
4. 날짜 선택이 끝나면 다음 단계 버튼을 눌러 예산 설정 단계로 이동한다.

### 2.4 예산 설정

1. 사용자는 최소 예산과 최대 예산을 입력한다.
2. 최소 예산이 최대 예산보다 크면 다음 단계로 이동할 수 없다.
3. 유효한 예산을 입력하면 다음 단계 버튼이 활성화된다.
4. 다음 단계 버튼을 눌러 관계 선택 단계로 이동한다.

### 2.5 관계 선택 및 코스 생성

1. 사용자는 친구, 연인, 가족 중 코스 참여자와의 관계를 선택한다.
2. "방 만들기" 버튼을 누른다.
3. 앱은 코스 생성 요청을 보낸다.
4. 생성 중에는 로딩 화면을 표시한다.
5. 생성이 성공하면 완료 화면으로 이동한다.
6. 사용자는 초대 링크를 확인하고 복사할 수 있다.
7. 완료 버튼을 누르면 홈 화면으로 돌아간다.

## 3. 초대 코드로 코스 참여

1. 사용자는 홈 FAB에서 "초대된 그룹 들어가기"를 선택한다.
2. 초대 코드 입력 화면으로 이동한다.
3. 초대 코드를 입력하면 입장 버튼이 활성화된다.
4. 입장 버튼을 누르면 코스 참여 요청을 보낸다.
5. 참여가 성공하면 홈 화면으로 돌아간다.
6. 실패하면 오류 메시지를 토스트로 확인한다.

## 4. 예정 코스 목록

### 4.1 목록 확인

1. 사용자는 홈 화면의 "생성한 방 보러가기" 섹션을 누른다.
2. 예정 코스 목록 화면으로 이동한다.
3. 앱은 사용자가 생성했거나 참여 중인 코스 목록을 불러온다.
4. 사용자는 각 코스의 이름, 날짜, 멤버 수, 담아 놓은 장소 수를 확인한다.
5. 목록이 없으면 빈 상태 안내를 확인한다.

### 4.2 날짜 필터 사용

1. 사용자는 날짜 필터 아이콘을 누른다.
2. 날짜 선택 다이얼로그에서 특정 날짜를 선택한다.
3. 선택한 날짜에 해당하는 코스만 목록에 표시된다.
4. 초기화 버튼을 누르면 전체 목록으로 돌아간다.

### 4.3 코스 선택

1. 사용자는 코스 목록에서 원하는 코스 카드를 선택한다.
2. 선택한 코스 ID를 기준으로 장소 추천 및 코스 구성 화면으로 이동한다.

## 5. 장소 추천 및 코스 구성

### 5.1 화면 진입 및 코스 정보 로딩

1. 사용자는 예정 코스 목록에서 코스를 선택한다.
2. 앱은 코스 요약, 멤버 목록, 추천 장소 목록, 코스에 담긴 장소 목록을 불러온다.
3. 지도에는 현재 선택된 모드에 맞는 장소 마커가 표시된다.
4. 기본 모드는 추천 모드이며 AI 추천 탭이 선택된다.

### 5.2 추천 장소 확인

1. 사용자는 추천 모드에서 바텀시트를 확인한다.
2. AI, 참여자, 전체 탭으로 추천자를 필터링한다.
3. 추천 장소 카드에서 장소명, 주소, 카테고리, 예상 가격, 좋아요 수, 댓글 수를 확인한다.
4. 장소 카드를 누르면 해당 장소가 선택되고 지도 마커가 강조된다.

### 5.3 장소 검색

1. 사용자는 지도 위 검색창에 장소명 또는 주소를 입력한다.
2. 키보드 검색을 실행하면 장소 검색 요청을 보낸다.
3. 검색 결과가 있으면 검색 결과 바텀시트에 장소 카드가 표시된다.
4. 검색 결과가 없으면 빈 검색 결과 안내를 확인한다.
5. 검색창의 삭제 버튼을 누르면 검색어와 검색 결과가 초기화된다.

### 5.4 장소 추천하기

1. 사용자는 검색 결과 또는 추천 장소 카드에서 추천하기 버튼을 누른다.
2. 앱은 선택한 장소를 코스방 추천 목록에 추가한다.
3. 성공하면 추천 목록에 추가되었다는 메시지를 표시한다.
4. 추천 목록은 다시 불러온 코스 상세 정보에 반영된다.

구현상 주의: 장소 검색 명세는 검색 결과에 `placeId`를 제공하지 않는다고 설명한다. 현재 추천 요청은 서버 `placeId`가 있어야 동작하므로, 명세 그대로 응답이 오면 검색 결과에서 바로 추천하기가 실패할 수 있다.

### 5.5 좋아요 누르기

1. 사용자는 추천 장소 카드의 좋아요 버튼을 누른다.
2. 아직 좋아요를 누르지 않은 장소라면 좋아요 요청을 보낸다.
3. 앱은 코스 상세 정보를 다시 불러와 좋아요 수와 내 좋아요 상태를 갱신한다.
4. 이미 좋아요를 누른 장소는 추가 요청을 보내지 않고 최신 상세 정보를 다시 불러온다.

구현상 주의: 현재 흐름은 좋아요 취소 API가 없으므로 토글이 아니라 1회 좋아요 등록 중심으로 동작한다.

### 5.6 댓글 작성

1. 사용자는 추천 장소 카드의 댓글 버튼을 누른다.
2. 댓글 화면으로 이동한다.
3. 댓글 내용을 입력한다.
4. 등록 버튼을 누르면 댓글 작성 요청을 보낸다.
5. 성공하면 댓글 목록에 방금 작성한 댓글이 추가된다.

구현상 주의: 현재 구현은 댓글 작성 API만 사용하고, 기존 댓글 목록을 서버에서 조회하는 별도 API는 사용하지 않는다. 화면에 표시되는 댓글 목록은 앱 내부에서 유지되는 댓글 중심이다.

### 5.7 장소를 코스에 담기

1. 사용자는 추천 장소 카드에서 코스에 넣기 버튼을 누른다.
2. 앱은 해당 장소를 현재 코스 장소 목록에 포함한 상태로 갱신한다.
3. 코스 모드로 전환하면 담긴 장소 목록과 방문 순서를 확인한다.

구현상 주의: 현재 코스 장소 담기, 삭제, 순서 변경은 `feature/58-course-api`의 코스 구성 화면 안에서 서버 API 호출 없이 로컬 상태로 처리된다. 앱을 다시 로드하면 서버의 `isSelected` 또는 코스 장소 목록 기준으로 복원된다.

### 5.8 코스 모드 확인 및 순서 변경

1. 사용자는 추천/코스 모드 전환 버튼에서 코스 모드를 선택한다.
2. 바텀시트에서 코스에 담긴 장소 목록을 순서대로 확인한다.
3. 장소를 드래그하여 순서를 바꾼다.
4. 장소 삭제 버튼을 누르면 목록에서 제거된다.

구현상 주의: 코스 구성 화면의 순서 변경은 서버 순서 변경 API와 연결되어 있지 않고 로컬 상태만 바꾼다. 오늘 탭의 진행 중 코스 순서 변경은 별도 Today API를 사용한다.

### 5.9 저장된 장소 불러오기

1. 사용자는 추천 바텀시트에서 저장된 장소 불러오기를 누른다.
2. 저장된 장소 선택 화면으로 이동한다.
3. 가져올 장소를 선택한다.
4. 가져오기가 완료되면 장소 추천 화면으로 돌아온다.
5. 앱은 선택한 저장 장소를 추천 목록에 추가한다.

## 6. 코스 설정 편집

1. 사용자는 장소 추천 및 코스 구성 화면 상단의 편집 아이콘을 누른다.
2. 코스 설정 편집 화면으로 이동한다.
3. 앱은 현재 코스명, 지역, 날짜, 예산 정보를 불러온다.
4. 사용자는 코스명, 지역, 날짜, 예산을 수정한다.
5. 유효하지 않은 입력이 있으면 저장할 수 없다.
6. 저장 버튼을 누르면 코스 설정 수정 요청을 보낸다.
7. 성공하면 이전 화면으로 돌아간다.

## 7. 현재 구현에서 API만 준비된 항목

아래 기능은 원격 API 선언 또는 DTO는 존재하지만, 사용자 화면 흐름에서 완전히 연결되어 있지 않다.

- AI 코스 후보 추천: `POST /courses/ai-recommendations` 원격 호출과 DTO는 있으나 화면에서 호출하는 UseCase와 UI 흐름이 없다.
- 코스 목록 기간 조회: Retrofit에는 `startDate`, `endDate` query가 있으나 현재 목록 화면은 전체 목록 조회 후 로컬 날짜 필터를 사용한다.
- 코스 구성 저장/확정: 추천 장소를 최종 코스에 담거나 순서를 바꾸는 코스 구성 화면의 동작은 서버 저장 API와 직접 연결되어 있지 않다.
